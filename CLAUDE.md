## Agent skills

### Issue tracker

Issues and specs live in this repo's GitHub Issues; use `gh`. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the default labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Use the multi-context layout: a root `GLOSSARY-MAP.md` points to relevant per-context `GLOSSARY.md` files; system ADRs live in `docs/adr/` and context ADRs alongside each context. See `docs/agents/domain.md`.
